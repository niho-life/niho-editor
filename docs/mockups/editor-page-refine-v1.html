鎌倉の朝の散歩

文字起こし

朝の七時、源氏山公園の芝生はまだ霜の名残で白っぽい。日が当たりはじめると、乾いた芝が少しずつ金色に変わっていく。

ベンチを探すのをやめて、そのまま芝に寝転んだ。持ってきた文庫本は三ページで止まり、空のほうを見ている時間のほうが長かった。

帰りは化粧坂を下りて、海蔵寺の前の茶屋で甘酒を一杯。観光客が増える前の一時間が、この町でいちばん静かな時間だと思う。

00:00じゃあ、源氏山のほうから歩いていきます。今朝はちょっと冷えますね。

00:42芝生のところ、朝のこの時間は誰もいなくて、霜がまだ残ってるんですよ。

01:15ここで少し休憩して、本を読もうかなと思ったんですけど、空がきれいで。

02:03化粧坂は滑りやすいので、下りは気をつけてください。石がけっこう濡れてます。

03:30海蔵寺の前の茶屋、甘酒が三百円。ここは九時から開いてます。
